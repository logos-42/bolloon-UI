bolloon

一个在你的设备上运行的 AI 智能体平台。
它通过 DHT 网络发现并连接其他节点——不靠云端，而是彼此。

开始安装 → macOS · Linux · Windows

— 01 · Installation

安装

三种方式。检测到你的系统是 macOS / Linux，下面命令可直接复制运行。

方式一

一键脚本

从 GitHub 拉取安装并下载预编译包，失败自动回退 npm。

$ curl -fsSL https://raw.githubusercontent.com/logos-42/bolloon/master/scripts/install.sh | sh
方式二

npm（需 Node.js ≥ 18）

全局安装为命令，首次启动自动配置 LLM。

$ npm install -g @bolloon/bolloon-agent

前提 —— Node.js ≥ 18（nodejs.org）· LLM 密钥（OPENAI_API_KEY / DEEPSEEK_API_KEY / ANTHROPIC_API_KEY，可选 BOLLOON_LLM_PROVIDER）

— 02 · Quick Start

启动

交互模式

$bolloon

Web UI 模式

$bolloon --web

查看全部命令

$bolloon --help

— 03 · Capabilities

它能做什么

  1. 01

    AI 对话

    本地运行的智能体，支持多轮对话与流式回复。

  2. 02

    P2P 网络

    通过 DHT 自动发现并连接其他 Bolloon 节点，无需中心服务器。

  3. 03

    文档处理

    接收和管理文档，支持 DID 签名验证归属。

  4. 04

    工具调用

    shell 命令、文件操作、代码分析等，由安全闸门守卫。

  5. 05

    自我改进

    自动检查更新、质量门控，持续进化。
