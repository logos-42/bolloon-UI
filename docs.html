— 01

用户故事与使用场景

在你的设备上运行一个本地智能体，并让它与网络中的其他节点协作。

常见场景：个人助手、文档整理、代码分析、多设备 P2P 协作。

— 02

快速开始

先安装（见安装页），然后直接运行：

$bolloon

首次启动自动配置 LLM，需设置一个环境变量（见配置）。

— 03

使用 Bolloon

CLI 交互模式（默认）

$bolloon

Web UI 模式

$bolloon --web

强制 CLI 模式

$bolloon --cli

查看全部命令

$bolloon --help

配置向导（首次运行也会自动进入）

$bolloon setup

切换／配模型供应商

$bolloon model

微支付信息（浏览／验真）

$bolloon x402 list

— 04

功能

  1. 01

    AI 对话

    本地运行的智能体，支持多轮对话与流式回复。

  2. 02

    P2P 网络

    通过 DHT 自动发现并连接其他节点。

  3. 03

    文档处理

    接收和管理文档，支持 DID 签名验证。

  4. 04

    工具调用

    shell、文件、精确补丁、代码执行、真浏览器、桌面操作与 git，由安全闸门守卫。

  5. 05

    自我改进

    自动检查更新、质量门控。

  6. 06

    微支付信息 (x402)

    把数据、技能、商品信息与作品标价提供；买方按 x402 付款后拿到带 Ed25519 签名的信封，验真分四档 (verified / self-attested / content-only / unverified)，来源与内容哈希都可核对。

  7. 07

    人机问答

    关键处智能体停下来问人 (CLI 下一行即答 / Web 弹层)，超时如实返回 expired，不伪造答案。

  8. 08

    技能沉淀与互传

    技能打包 → IPFS CID → bolloon://skill/<cid> 链接，自己留存也发给别的节点；安装带版本门、覆盖前备份、包内路径校验。

  9. 09

    勿扰时钟

    定时任务带跨进程 tick 锁、执行记录与熔断；主任务进行中后台 tick 让路并记 deferred，人忙完自动补跑。

— 05

消息平台

通过消息平台与你的节点对话，让智能体驻留在你常用的入口。具体接入方式见仓库。

— 06

集成

Bolloon 通过环境变量接入不同 LLM 提供商，并通过 DIAP 与世界其他节点互连。

提供方：OpenAI / DeepSeek / Anthropic。首次运行会进配置向导，密钥写入 ~/.bolloon/llm-config.json（不入仓库），也可随时用 bolloon model 切换。

— 07

指南与教程

从源码构建、接入 LLM、发现并连接节点——逐步指南见仓库 README 与 docs。

— 08

开发者指南

Build

克隆并构建

$git clone https://github.com/logos-42/bolloon.git && cd bolloon && npm install && npm run build:all && npm start

核心代码：src/agents（智能体）、src/cli（Ink 界面）、src/network（P2P）、src/web（Web UI）。

— 09

参考

变量说明
OPENAI_API_KEYOpenAI 提供商（可选）
DEEPSEEK_API_KEYDeepSeek 提供商（可选）
ANTHROPIC_API_KEYAnthropic 提供商（可选）
BOLLOON_LLM_PROVIDER指定 LLM 提供商
~/.bolloon/llm-config.json密钥与默认模型落盘位置（向导/ bolloon model 写入，不入仓库）
bolloon setup配置向导（首次运行自动进入）
bolloon model [key <provider>]切换模型供应商 / 配置密钥
bolloon x402 list|show|buy|verify微支付信息：浏览 / 详情 / 购买并验真
BOLLOON_CRON=0关闭后台时钟（勿扰时钟总开关）
BOLLOON_VERSION安装脚本：指定版本
BOLLOON_INSTALL_DIR安装目录，默认 /usr/local/bin
