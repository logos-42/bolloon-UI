— 01

用户故事与使用场景

在你的设备上运行一个本地智能体，并让它与网络中的其他节点协作。

常见场景：个人助手、文档整理、代码分析、多设备 P2P 协作。

— 02

快速开始

先安装（见安装页），然后直接运行：

$bolloon

首次启动自动配置 LLM，需设置一个环境变量（见配置）。

— 03

使用 Bolloon

CLI 交互模式（默认）

$bolloon

Web UI 模式

$bolloon --web

强制 CLI 模式

$bolloon --cli

查看全部命令

$bolloon --help

— 04

功能

  1. 01

    AI 对话

    本地运行的智能体，支持多轮对话与流式回复。

  2. 02

    P2P 网络

    通过 DHT 自动发现并连接其他节点。

  3. 03

    文档处理

    接收和管理文档，支持 DID 签名验证。

  4. 04

    工具调用

    shell、文件、代码分析，由安全闸门守卫。

  5. 05

    自我改进

    自动检查更新、质量门控。

— 05

消息平台

通过消息平台与你的节点对话，让智能体驻留在你常用的入口。具体接入方式见仓库。

— 06

集成

Bolloon 通过环境变量接入不同 LLM 提供商，并通过 DIAP 与世界其他节点互连。

提供方：OpenAI / DeepSeek / Anthropic。

— 07

指南与教程

从源码构建、接入 LLM、发现并连接节点——逐步指南见仓库 README 与 docs。

— 08

开发者指南

Build

克隆并构建

$git clone https://github.com/logos-42/bolloon.git && cd bolloon && npm install && npm run build:all && npm start

核心代码：src/agents（智能体）、src/cli（Ink 界面）、src/network（P2P）、src/web（Web UI）。

— 09

参考

变量说明
OPENAI_API_KEYOpenAI 提供商（可选）
DEEPSEEK_API_KEYDeepSeek 提供商（可选）
ANTHROPIC_API_KEYAnthropic 提供商（可选）
BOLLOON_LLM_PROVIDER指定 LLM 提供商
BOLLOON_VERSION安装脚本：指定版本
BOLLOON_INSTALL_DIR安装目录，默认 /usr/local/bin
