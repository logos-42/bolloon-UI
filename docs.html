Documentation · 文档

把主动权交还给设备

Bolloon 是命令行优先的本地智能体。这份手册覆盖安装后的每一步：启动、配置、命令，以及从源码构建。

— 01 · Quick Start

快速开始

先安装（见 安装页），然后直接运行：

$bolloon

首次启动会自动配置 LLM。需要设置一个环境变量（见 配置）。

— 02 · Commands

命令一览

CLI 交互模式（默认）

$bolloon

Web UI 模式

$bolloon --web

强制 CLI 模式

$bolloon --cli

查看全部命令

$bolloon --help

— 03 · Configuration

配置

通过环境变量配置 LLM 提供商。设置 OPENAI_API_KEY、DEEPSEEK_API_KEY 或 ANTHROPIC_API_KEY 之一即可。

变量说明
OPENAI_API_KEYOpenAI 提供商（可选）
DEEPSEEK_API_KEYDeepSeek 提供商（可选）
ANTHROPIC_API_KEYAnthropic 提供商（可选）
BOLLOON_LLM_PROVIDER指定 LLM 提供商
BOLLOON_VERSION安装脚本：指定版本
BOLLOON_INSTALL_DIR安装目录，默认 /usr/local/bin

— 04 · From Source

从源码构建

Build

克隆并构建

$git clone https://github.com/logos-42/bolloon.git && cd bolloon && npm install && npm run build:all && npm start

构建产物位于 dist/。核心代码在 src/agents（智能体）、src/cli（Ink 界面）、src/network（P2P）、src/web（Web UI）。
