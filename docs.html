怎么用

装好之后只有一件事要做:把目标说清楚。这一页按顺序讲三件事——三步开始、跑起来之后每一步发生了什么、东西落在哪。

目录

— 01

三步开始

需要 Node.js 18 以上。第三步换成你自己的目标就行。

1

装

$npm i -g @bolloon/bolloon-agent
2

跑

$bolloon

首次启动会问你用哪家模型,密钥只写进本机 ~/.bolloon/llm-config.json。

3

说一句目标

>把 src/web 里所有硬编码的端口号收成一个常量,改完跑类型检查

不用写步骤、不用挑工具——它自己拆。下面是它接下来会做的事。

要在浏览器里看:bolloon --web → http://127.0.0.1:54188

— 02

跑起来之后发生了什么

每一步都写成两行:你会看到什么,它同时在做什么。

  1. 先拆步骤,每一步都带一个能核对的出口

    你会看到一行行「这一步在做什么」——例如 「🔧 查看 git 状态 · git_status 327ms」,不刷思维流。它把目标拆成小步,每步都对应一个能验证的结果:命令退出码、测试是否通过、文件里到底是什么。

  2. 动手就当场验证,不拿「命令跑完」当「活干好了」

    改完代码先跑类型检查;写文件过写入门;工具回报成功之后它会读回确认一次。有明确的收尾判据才算完成——这也是它敢说自己干完了的依据。

  3. 卡住不硬顶:换一条路,或停下来告诉你

    退出码不是零不等于失败(钩子经常非零退出而动作已经生效)——它先核事实再下结论;命令被策略拦住,它换一条路而不是绕到更危险的做法;错误会先分类,再给出对应的下一步。

  4. 该你拍板的地方,它会停下来问

    你会看到一个问题加几个选项。发布、改生产环境、删除、花钱这类不可逆的取舍,它不替你做主。

  5. 干完必复盘,教训进库里(而且可以回滚)

    你会看到一行 「📚 复盘: …」,后面是这一轮真正学到的东西。教训写进技能库与判断力库;技能每次改动都进账本、可以单条回滚;自审只治理它自己造出来的技能,你点名要的归你。

  6. 长活可以离开现场:后台跑、派出去、被别的节点接手

    后台任务与服务的台账在本机(重启后会懒恢复并探活);派出去的子智能体不等它跑完,结果会回到下一轮;接进网络之后,别的节点可以按能力找到它、把活派给它——见网关页。

— 03

命令速查

在终端里

命令做什么
bolloon启动,进入交互会话
bolloon --web浏览器界面(本机 54188)
bolloon --help全部命令
bolloon setup status看配置与连通性状态
bolloon model key <provider>配或换模型密钥
bolloon x402 list微支付信息:浏览 / 详情 / 购买 / 验真

在对话里(直接发,以 / 开头)

指令做什么
/goal立一个目标,让它自己往下推进
/plan · /queue看计划 / 排队的活
/trace看这一步在做什么(执行描述)
/skills · /memory技能库 / 记忆
/tools它手上有什么工具
/p2p · /net网络与邻居节点
/session · /sessions会话历史
/wallet · /payments钱包与支付
/help全部指令

— 04

东西落在哪

全在本机 ~/.bolloon/ 下,不上传。

路径里面是什么
llm-config.json模型供应商与密钥(不入任何仓库)
logs/tool-calls.jsonl每一次工具调用:名称、参数摘要、耗时
logs/experience-review.log每轮复盘的过程与结果
skills/技能库(本机现在 1351 个)
human-values/判断力:判据与用法记录
processes.json后台任务与服务台账(重启后懒恢复)
sessions/会话历史
wallet-signatures.jsonl钱包签名记录

边界

已经稳

终端交互 · 技能库与提炼 · 工具调用与类型门 · 后台任务与服务 · 链上任务与结算 · 节点发现与委派。

不会承诺

— 06

自己构建

Build

从源码到本机可跑

$git clone https://github.com/logos-42/bolloon.git && cd bolloon && npm install && npm run build:all && npm start

核心代码:src/agents(智能体循环与工具)、src/cli(终端界面)、src/network(节点与发现)、src/web(Web UI)。
